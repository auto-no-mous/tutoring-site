# it-tutor.pro

Платформа для подготовки к ЕГЭ/ОГЭ по информатике. ТЗ — `project_description.md`.

## Быстрый локальный запуск

```
.\run-local.ps1
```

Ставит зависимости, применяет миграции, поднимает backend и frontend каждый в
своём окне PowerShell и открывает сайт в браузере (http://127.0.0.1:5173).
Если зависимости уже установлены — `.\run-local.ps1 -SkipInstall` быстрее.
Остановить — закрыть открывшиеся окна или Ctrl+C в каждом.

## Backend (FastAPI + Poetry)

```
cd backend
poetry install
copy .env.example .env   # при необходимости поменять секреты/SMTP/VK
poetry run alembic upgrade head
poetry run uvicorn app.main:app --reload --port 8000
poetry run pytest
```

Swagger: http://127.0.0.1:8000/docs

Создать единственный аккаунт администратора:

```
poetry run python -m app.scripts.create_admin --email admin@it-tutor.pro --password ...
```

Разослать напоминания о ближайших занятиях (раздел 2.7); в проде запускать по
расписанию (cron/systemd timer/Task Scheduler) — планировщик внутри приложения не
поднят:

```
poetry run python -m app.scripts.send_reminders
```

## Frontend (Vue 3 + Vite + Tailwind)

```
cd frontend
npm install
npm run dev      # http://127.0.0.1:5173, проксирует /api и /files на backend:8000
npm run build
```

## Docker / прод

```
cd backend && copy .env.example .env   # заполнить JWT_SECRET_KEY и остальные секреты
cd ..
docker compose up --build -d
```

Поднимает два контейнера: `backend` (gunicorn+uvicorn, применяет миграции при
старте через `docker-entrypoint.sh`) и `nginx` (отдаёт собранный фронтенд и
проксирует `/api`, `/files` на backend). SQLite-файл и загруженные файлы живут на
именованном томе `backend_storage`. Порт 80 публикуется наружу; TLS-терминация
(например, через отдельный Traefik/Certbot) не настроена — добавляется отдельно
при выходе в прод. Миграция с SQLite на PostgreSQL (раздел 9) — сменить
`DATABASE_URL` на `postgresql+asyncpg://...` в `docker-compose.yml`.

## Статус реализации

См. `project_description.md` за полным ТЗ.

Backend — реализовано и покрыто тестами (`poetry run pytest`, 45+ тестов): модель
данных, регистрация/логин (email+пароль, VK OAuth), JWT access+refresh,
подтверждение email, сброс пароля, анкеты репетиторов и публичный каталог,
типы занятий, движок расписания/слотов (учёт перерыва, шага сетки, часовых
поясов, минимального запаса времени), бронирования (ручные брони, еженедельная
регулярность, отмена/перенос по политике репетитора), групповые занятия
(заявки, зачисление, отдельные даты, выход из группы), домашние задания (ссылка
или файл, отметка «выполнено» или загрузка файла), чат (личный и групповой),
уведомления (Telegram/email, лог рассылки), отзывы и рейтинг, статистика
репетитора/ученика, админка (полный CRUD по репетиторам/ученикам/занятиям/
группам), докер-деплой.

Frontend — SPA на Vue 3 + Vite + Tailwind (роутинг, JWT-авторизация с
автообновлением токена, светлая/тёмная тема, правовые страницы). Публичный
каталог с фильтрами и анкета репетитора с мастером записи (тип занятия → дата →
время → подтверждение, время показывается в местном часовом поясе ученика и в
скобках по МСК). Личный кабинет с вкладками: у репетитора — профиль/анкета,
типы занятий, расписание, занятия (ручные брони, ссылки), группы (заявки,
состав, отдельные даты), домашние задания (выдача и просмотр сдач), чат,
статистика, настройки уведомлений; у ученика — занятия (отмена/перенос/
остановка регулярности), группы (заявки, выход), домашние задания (отметка/
загрузка файла), чат, статистика, настройки.

Известные ограничения V1: в интерфейсе репетитора ученик для ручной записи/
домашнего задания указывается по ID (нет поиска по имени/почте — такого
эндпоинта нет в API); календарного виджета нет, списки простые; дизайн
утилитарный (Tailwind без кастомной темы). Docker не проверялся сборкой в этом
окружении (Docker не установлен) — YAML провалидирован, но соберите образы
перед первым деплоем.
