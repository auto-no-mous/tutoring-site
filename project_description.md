# Сайт it-tutor.pro — Техническое задание

Домен it-tutor.pro куплен.

## 1. Общее описание

Платформа для подготовки к экзаменам по информатике (ЕГЭ/ОГЭ и т.п.), связывающая репетиторов и учеников. Ученики находят репетитора в каталоге, записываются на занятия, получают и сдают домашние задания. Репетиторы ведут расписание, учеников, домашние задания, переписку и статистику.

Три роли: репетитор, ученик, администратор.

## 2. Функциональность репетитора

### 2.1 Анкета
- Фото, к чему готовит (предмет/экзамен), о себе, достижения
- Анкета может быть скрыта из общего каталога и доступна только по прямой ссылке

### 2.2 Типы занятий
Репетитор создаёт один или несколько типов занятий, у каждого:
- название (например, «Индивидуальное занятие», «Разбор варианта ЕГЭ»)
- формат: индивидуальный или групповой
- длительность
- цена (для группового формата — цена за одно место)

Тип занятия с групповым форматом служит основой для группы подготовки (см. 2.11): вместимость, расписание и состав участников настраиваются отдельно на уровне конкретной группы.

### 2.3 Расписание
- Репетитор указывает рабочие дни и интервалы доступности в каждом дне (например, 09:00–14:00, 14:00–18:00)
- Настраивается перерыв между занятиями (например, после занятия длительностью 60 минут — перерыв 15 минут: если ученик занял 09:00, следующая запись возможна не раньше 10:15)
- Шаг разбивки времени (гранулярность сетки слотов на выбор): 10 / 15 / 20 / 30 минут, на выбор репетитора; по умолчанию — 15 минут. Настройка общая на всё расписание репетитора. Длительности типов занятий и перерыв между занятиями должны быть кратны выбранному шагу
- Минимальный запас времени перед началом занятия, за который ещё можно на него записаться (слоты внутри этого запаса недоступны для новой записи). Настраивается репетитором; по умолчанию — сутки (24 часа)
- В личном кабинете репетитора расписание всегда отображается по МСК, независимо от часового пояса репетитора
- Рядом с занятиями учеников не из МСК — пометка о разнице поясов, например «часовой пояс ученика: МСК+3» (подробнее — раздел 6)

### 2.4 Бронирования и слоты
- Полный CRUD по записям на занятия
- Репетитор может создать запись о занятии вручную без привязки к ученику — это резерв времени/заглушка, к которой позже можно привязать ученика или оставить как личную блокировку времени
- Поддержка регулярного (еженедельного повторяющегося) бронирования на одно и то же время с одним учеником, без ручного создания записи каждую неделю (для групповых занятий периодичность задаётся иначе — см. 2.11)

### 2.5 Отмена и перенос занятия учеником
Применяется только к индивидуальным занятиям (для групповых занятий отмена/перенос учеником недоступны — см. 2.11, 3.3). Настраиваются как две независимые политики:
- **Отмена**: минимальный срок до занятия (например, за 24 часа, за 12 часов), лимит количества отмен в месяц
- **Перенос**: отдельные от отмены сроки и лимиты, настраиваются самостоятельно

### 2.6 Ссылка на занятие
- Занятие проводится на стороннем ресурсе (Zoom/Google Meet/др.); репетитор указывает ссылку отдельно для каждого ученика

### 2.7 Уведомления
Через Telegram и/или email, о событиях:
- новая запись на занятие
- предстоящее занятие (напоминание)
- изменение в расписании (отмена/перенос со стороны ученика)
- новая заявка на участие в группе, отказ ученика от участия в группе
- новое сообщение в чате (личном или групповом)
- другие важные события (уточняются в процессе проектирования)

### 2.8 Домашние задания
- Отправка ученику домашнего задания в виде ссылки на сторонний ресурс или файла

### 2.9 Чат
- Личные сообщения с учеником, история переписки сохраняется в системе

### 2.10 Статистика
- Всего проведено занятий
- Количество выполненных домашних заданий
- Количество разных учеников за месяц
- (точный набор показателей уточняется на этапе проектирования UI)

### 2.11 Групповые занятия
- Репетитор создаёт группы подготовки: название/направление, тип занятия и цена за место, максимальная вместимость (обязательна), периодичность и время занятий (например, «вторник и четверг, 18:00») — расписание группы задаёт только репетитор, ученик его не выбирает
- У каждой группы — единая ссылка на занятие (сторонний ресурс), общая для всех участников
- Минимальное количество участников для проведения занятия не требуется
- Лист ожидания не предусмотрен: при превышении вместимости репетитор вручную решает, кого зачислить
- Ученики не записываются в группу сами — они подают заявку на конкретную группу (см. 3.3), а зачисление выполняет репетитор вручную
- Зачисление в группу происходит один раз: после зачисления ученик закреплён за группой на все последующие занятия автоматически, без повторной записи каждую неделю
- Ученик выбывает из группы только по собственному отказу от занятий (место освобождается); отмена или перенос отдельного занятия группы учеником невозможны
- Репетитор сохраняет полный CRUD над группой, её расписанием, составом участников и конкретными датами занятий (например, может отменить/перенести отдельное занятие при необходимости)
- Домашнее задание отправляется всей группе одновременно; выполнение отслеживается по каждому ученику отдельно
- Групповой чат: общий чат репетитора со всеми текущими участниками группы, отдельно от личных сообщений 1-на-1 (см. 2.9), которые остаются доступны всегда
- В статистике репетитора одно групповое занятие считается одним проведённым занятием; в статистике каждого ученика — засчитывается индивидуально

## 3. Функциональность ученика

### 3.1 Каталог и запись
- Публичный каталог анкет репетиторов с фильтрацией по цене и предмету/направлению подготовки
- Отзывы и рейтинг репетиторов от учеников

Процесс записи на индивидуальное занятие:
1. Ученик открывает анкету репетитора и нажимает «Записаться на занятие»
2. Выбирает тип занятия из настроенных репетитором (название, длительность, цена — см. 2.2)
3. Выбирает дату из доступных (дни без единого доступного слота под выбранную длительность не показываются как доступные)
4. Выбирает время на сетке с шагом разбивки, заданным репетитором (см. 2.3). На сетке видны все отметки в пределах рабочих интервалов дня, но выбрать можно только те, что вмещают полную длительность занятия и перерыв после него, не пересекаясь с уже существующими записями — остальные отображаются неактивными. Пример: занятие 09:00–10:00 длительностью 60 минут с перерывом 15 минут при шаге разбивки 15 минут делает неактивными отметки 09:00, 09:15, 09:30, 09:45, 10:00 — ближайшая доступная отметка для новой записи: 10:15
5. Финальный экран подтверждения: репетитор, тип занятия (название/длительность/цена), дата и время (в часовом поясе ученика, с пометкой МСК рядом — см. раздел 6), чекбокс «Повторять каждую неделю», кнопка «Записаться»

Оформленную еженедельную регулярность можно в любой момент отменить в личном кабинете ученика — это останавливает создание новых занятий серии на будущее; уже созданные предстоящие занятия серии при этом не отменяются автоматически и отменяются по обычным правилам (раздел 2.5), если ученик хочет отменить и их отдельно.

### 3.2 Личный кабинет
- Список ближайших занятий
- Отправка домашнего задания файлом либо отметка «выполнено» — поведение задаёт репетитор
- Отмена индивидуального занятия (в рамках политики репетитора)
- Перенос индивидуального занятия (в рамках отдельной политики репетитора); для групповых занятий — см. 3.3
- Переход по ссылке на занятие
- Чат с репетитором с сохранённой историей переписки
- Статистика: количество проведённых занятий, доля выполненных домашних заданий и т.д.

### 3.3 Групповые занятия
- Ученик видит группы подготовки репетитора (направление, цена за место, периодичность) и может подать заявку на участие в конкретной группе
- Зачисление в группу выполняет репетитор вручную; после зачисления ученик автоматически участвует во всех последующих занятиях группы без необходимости отдельной записи
- В личном кабинете групповые занятия отображаются в общем списке ближайших занятий наравне с индивидуальными
- Отмена и перенос отдельного группового занятия учеником недоступны — единственный способ покинуть группу — отказаться от занятий полностью, освободив место
- Домашнее задание по групповым занятиям — как и по индивидуальным: файл или отметка «выполнено» (поведение задаёт репетитор)
- Групповой чат со всеми участниками и репетитором, а также отдельный личный чат 1-на-1 с репетитором

## 4. Функциональность администратора
- Единственный аккаунт администратора, полный доступ ко всей системе
- Полный CRUD по репетиторам, включая их анкеты
- Полный CRUD по ученикам
- Полный CRUD по занятиям (записям на занятия, включая групповые занятия, заявки и состав групп)

## 5. Оплата занятий
- **V1 (текущая версия)**: оплата происходит вне сайта, по договорённости между репетитором и учеником. Цена на сайте — информационная, для выбора репетитора и типа занятия (для групповых занятий — цена за место, см. 2.2, 2.11)
- Возврат средств при отмене занятия в V1 полностью выполняется репетитором вручную вне сайта; сайт этот процесс не регулирует
- **V2 (следующая версия)**: приём оплаты на сайте — выбор платёжного провайдера будет определён отдельно

## 6. Часовые пояса
- Часовой пояс ученика определяется автоматически (с возможностью ручной коррекции)
- Ученику везде отображается его локальное время, рядом в скобках — время по МСК, например «18:00 (МСК 15:00)»
- Репетитору в личном кабинете расписание всегда отображается по МСК
- Рядом с занятиями с учениками из другого пояса — пометка о разнице, например «часовой пояс ученика: МСК+3»

## 7. Регистрация и аутентификация
- V1: регистрация по email + паролю, а также через VK (OAuth) — доступны обе роли, репетитор и ученик
- Номер телефона не запрашивается и не требуется ни при регистрации, ни в дальнейшем ни при каких обстоятельствах
- Подтверждение email при регистрации через email + пароль
- Восстановление пароля через email (для аккаунтов, зарегистрированных через email + пароль)
- Привязка VK к уже существующему аккаунту email+пароль (и наоборот) выполняется пользователем вручную в настройках профиля, а не автоматически (см. также раздел 10 про ограничения VK OAuth)

## 8. Внешний вид
- Современный, адаптивный дизайн (десктоп/планшет/мобильные устройства)
- Светлая и тёмная темы

## 9. Технологический стек
- Backend: Python, FastAPI
- Пакетный менеджер: Poetry
- БД: SQLite на старте, миграция на PostgreSQL при публикации сайта
- Frontend: Vue
- Telegram-интеграция: python-telegram-bot (уведомления, см. раздел 2.7)

## 10. Технические моменты на своё усмотрение

По мелочи то, что нигде явно не оговорено, но по факту придётся решить в процессе разработки:

- Авторизация — JWT (access + refresh), т.к. фронт отдельным SPA на Vue дёргает FastAPI как обычный API
- Файлы (фото анкет, домашки) — сначала просто на диске сервера; если нагрузка вырастет, переезжаем на S3-совместимое хранилище, скорее всего Яндекс Object Storage, чтобы данные физически оставались в РФ
- Деплой — Docker/docker-compose, спереди Nginx, за ним Uvicorn/Gunicorn
- Аудитория сайта — РФ, храним email, фото, переписку — значит нужны политика конфиденциальности, пользовательское соглашение и чекбокс согласия на обработку персональных данных при регистрации (152-ФЗ)
- Отзыв может оставить только ученик, у которого было хотя бы одно занятие с этим репетитором; один отзыв на пару репетитор-ученик, с возможностью отредактировать
- По VK есть нюанс: VK OAuth не всегда отдаёт email (нужен отдельный скоуп и ревью приложения в VK), поэтому пользователя опознаём по VK ID, а не по почте. Привязку VK к уже существующему аккаунту делаем вручную через настройки профиля — автоматически по почте не склеиваем, чтобы не подвязать чужой аккаунт по ошибке

## 11. Что не делаем в первой версии
- Приём оплаты на сайте
- Мобильное приложение
- Другие предметы, кроме информатики
- Вход через другие соцсети или по номеру телефона
