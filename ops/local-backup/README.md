# Бэкап на свой компьютер

Серверные бэкапы (`ops/backup.sh`, каждую ночь в 03:15 UTC) лежат на том же
сервере, что и сайт, и не спасут, если пропадёт сам сервер. Этот скрипт кладёт копию
на ваш компьютер под Windows - запускается вручную, когда нужно.

## Запуск

Двойной щелчок по `backup-to-local.cmd` - или из PowerShell:

```
.\ops\local-backup\backup-to-local.ps1
```

Что он делает:

1. запускает на сервере `ops/backup.sh` - тот же архив, что и ночной: дамп базы,
   все загруженные файлы, серверные настройки (`backend/.env`, корневой `.env`,
   `docker-compose.override.yml`, `ops-nginx/`);
2. скачивает архив по `scp`, при обрыве связи повторяет до трёх раз;
3. сверяет контрольную сумму с серверной и проверяет, что архив читается и в нём
   есть база, файлы и настройки;
4. кладёт его в `%USERPROFILE%\Backups\my-tutor` с датой и временем в имени и
   хранит последние 30, старые удаляет (другие файлы в папке не трогает).

Параметры:

| Параметр | Что делает |
| --- | --- |
| `-Destination D:\Backups\my-tutor` | другая папка |
| `-Keep 10` | сколько последних архивов хранить |
| `-UseLatest` | не делать свежий бэкап, скачать последний готовый (ночной) |
| `-SshHost my-tutor` | алиас сервера из `~/.ssh/config` |

Нужны клиент OpenSSH (в Windows 10/11 стоит по умолчанию) и вход на сервер по
алиасу `my-tutor` из `%USERPROFILE%\.ssh\config` с ключом `ops/secrets/deploy_key`.
Проверить: `ssh my-tutor true` должен пройти без пароля.

## Где хранить

В архиве персональные данные учеников (база) и всё, что открывает сайт: пароль базы,
токен Telegram-бота, секрет подписи сессий (`backend/.env`). Поэтому:

- держите папку на диске, к которому нет доступа у посторонних; лучше всего -
  на диске с BitLocker;
- не кладите её в облачную синхронизацию (OneDrive, Яндекс Диск) без шифрования;
- если копируете на флешку или внешний диск - тоже зашифрованный.

Приватный DKIM-ключ почты в архив не входит (см. `ops/mail/README.md`, раздел 3):
при переезде на новый сервер его либо копируют отдельно, либо выпускают новый.

## Восстановление

Архив - обычный `tar.gz`: распаковать можно встроенным `tar` Windows
(`tar -xzf my-tutor-....tar.gz`) или 7-Zip. Внутри `db.dump`, `storage/`, `config/`.
Как поднять из него сервер - `ops/README.md`, раздел «Бэкапы».
